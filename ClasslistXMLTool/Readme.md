* This batch file takes a text file list of type names and creates an XML out of them for types.xml in DayZ or vise versa
* Simply download the .bat file
* Drag a classlist txt file onto the proper batch file in Windows Explorer, and a types.XML of the same name will be created
* Drag a types.xml file onto the proper batch file in Windows Explorer, and a TXT of the same name will be created
* You can edit the template defaults in the batch file to suit your needs
