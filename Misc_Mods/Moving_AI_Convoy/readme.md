# Loot Settings for Moving AI Convoy
* All Vanilla gear
* 2 files to chose from
  * One is 100% to spawn - *labeled with '100', so name needs '100' to be removed before use*
  * One is less than 100% to spawn - affects only the groups
* Groups have been moved to the bottom of the file for ease of use
* Added Supplies Group - misc toos and materials
* Added Explosives Group - nades, thumpers & claymores
* All gun attachments spawn separately in the vehicle inventory, and players assemble them - 100% chance to get attachments and mags
* Featured in [Deer Isle Grand Prix](https://steamcommunity.com/sharedfiles/filedetails/?id=3840609739)
