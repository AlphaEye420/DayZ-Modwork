* This batch file takes a text file list of type names and creates an XML out of them for types.xml in DayZ or vise versa
* Simply download the .bat file, then drag a txt file onto the batch file in Windows Explorer, and an XML of the same name will be created, or drag a types.xml to the xml to class-list .bat file to make a quick class-list
* Copy from the created file to paste into the types file of your choosing
* You can edit the template defaults in the batch file to suit your needs
